## 🔗 和仿真作业的对应关系

笔记里推导的公式，都在仿真作业里做了验证：

| 笔记里的公式 | 对应作业 | 仿真验证结果 |
| --- | --- | --- |
| `τ = RC`、`fc = 1/(2πRC)` | [① RC 低通滤波](../README.md#-rc-低通滤波电路) | τ 仿真 150.050 μs vs 理论 150 μs（**误差 0.03 %**） |
| 波特图 −3 dB 点、−20 dB/dec | [① RC 低通滤波](../README.md#-rc-低通滤波电路) | fc 仿真 1059.25 Hz vs 理论 1061.03 Hz（**误差 0.17 %**） |
| `V_th`、`R_th`、`I_sc = V_th/R_th` | [② 验证戴维南定理](../README.md#-验证戴维南定理) | V_th 误差 **0.0001 %**；8 种负载下原电路与等效电路完全一致 |
| `I_D = ½K(V_GS−V_th)²`、饱和区判据 | [③ NMOS 共源放大](../README.md#-nmos-共源级放大电路) | I_D 误差 **0.0000 %**，V_DS 误差 **0.0000 %** |
| `g_m = 2I_D/(V_GS−V_th)` | [③ NMOS 共源放大](../README.md#-nmos-共源级放大电路) | g_m 误差 **0.00 %** |
| `A_v = −g_m(R_d∥r_o)` | [③ NMOS 共源放大](../README.md#-nmos-共源级放大电路) | A_v 误差 **0.13 %**，相位 −180°（反相） |

## 📝 几点说明

**关于符号**：笔记里的 R₁、R₂ 就是作业题卡里的 **Rg1、Rg2**（分压偏置电阻）；笔记里还讨论了带 Rs 的一般情况，而作业电路是**源极直接接地**的简化形式（V_S = 0）。

**关于记录方式**：手写在活页本上，手机拍照。第 1 页和第 3 页的电路图和网表是画/抄在笔记上的。
