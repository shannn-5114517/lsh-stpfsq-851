## 🧪 和参数实验的呼应（第 10 页）

**第 10 页记的「本征增益」，正好在参数实验里被验证了**：

| 笔记里的公式 | 实验里看到的 |
| --- | --- |
| `A_int = g_m·r_o` | [实验六](../experiments/README.md) 发现：λ 越小，这个「天花板」越高 |
| `A_int = 2V_A/V_ov`，`V_A = 1/λ` | λ 从 0.02 减小到 0.005（1/4），本征增益从约 **100 倍**抬到约 **400 倍** |

**所以笔记和实验是**：

```
笔记：记下公式 A_int = gm·ro = 2/(λ·Vov)     ← 理论
        ↓
实验：把 λ 改小，看增益天花板是不是真的抬高   ← 验证
        ↓
结论：λ ∝ 1/L，所以加长沟道就能提高本征增益   ← 设计指导
```

> **这就是「理论 → 仿真 → 设计」的完整闭环** —— 笔记是理论，实验是验证，最后落到设计决策。
